# Bandit

## What is Bandit?

Bandit is a beginner-friendly wargame from [OverTheWire](https://overthewire.org/wargames/bandit/)
designed to teach the basics of Linux, the command line, and security concepts.
You connect to a remote machine over SSH, and each level challenges you to find
the password that unlocks the next one. Along the way you practice essential
skills like navigating the file system, working with permissions, searching and
filtering data, and using common networking and security tools.

## About This Repository

I created this repository to track my progress through Bandit and to keep my
notes in one place so I can come back to them later.

I'm working through the game in order, starting from Level 0 and moving up one
level at a time until I reach the final level. For each level, I document:

- The goal of the level
- The commands and approach I used
- What I learned along the way

Feel free to look around, and if you're playing Bandit yourself, try each level
on your own first. Use these notes only when you're really stuck.
